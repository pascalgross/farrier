Revoking removes the certificate this control plane authenticates the host by, which is the whole of the revocation mechanism: the fingerprint is looked up on every request, so the next one fails. Its machine id stops matching too, which is what lets this machine enrol again after a rebuild.

It does not stop the agent and it does not stop the machine being patched. A revoked host keeps applying updates from its own local policy, because a host that fell off the fleet must not quietly become an unpatched one. Nothing here is deleted: the host, its jobs and its history stay.
